Cómo jugar Caballero Místico

Explora las habitaciones, derrota enemigos, recoge Azari y consigue habilidades para avanzar por la aventura.

Controles

Usa A y D para moverte, Espacio para saltar y ESC para abrir el menú. En móvil y tablet puedes usar los controles táctiles.

Progresión

Visita las tiendas para comprar armas, bombas, bendiciones y mejoras. Busca llaves, puertas y secretos mientras te preparas para los jefes.
